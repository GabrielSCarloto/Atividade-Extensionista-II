# Projeto de Inclusão Digital

Este projeto foi desenvolvido como parte da Atividade Extensionista II do curso de Ciência de Dados.

## Objetivo
Promover a inclusão digital por meio da coleta e análise de dados e desenvolvimento de material educativo.

## Tecnologias utilizadas
- Google Forms
- Microsoft Excel
- GitHub

## Etapas do projeto
1. Criação e aplicação do formulário
2. Coleta de dados
3. Análise dos dados
4. Desenvolvimento de material educativo

## Resultados
Os dados coletados estão disponíveis no arquivo formulario.csv.

## Material desenvolvido
O guia de informática básica está disponível no arquivo guia.pdf.
